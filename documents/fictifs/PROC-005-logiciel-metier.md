# PROC-005 - Incident sur un logiciel métier

## Catégorie

Applications métier

## Symptômes

- Application inaccessible.
- Message d'erreur lors de l'ouverture.
- Fonctionnalité indisponible.
- Lenteur importante.

## Procédure

1. Identifier l'application concernée.
2. Recueillir le message d'erreur sans collecter de données de patients.
3. Vérifier si le problème touche plusieurs utilisateurs.
4. Contrôler la connectivité réseau.
5. Vérifier l'existence d'un incident connu.
6. Transmettre au support applicatif si nécessaire.

## Sécurité

Ne jamais inclure de données médicales réelles dans un ticket de démonstration.
Ne pas effectuer de manipulation sur des données de production sans habilitation.

## Escalade

Si l'incident bloque une activité de soins, prévenir immédiatement le support habilité selon la procédure interne.
