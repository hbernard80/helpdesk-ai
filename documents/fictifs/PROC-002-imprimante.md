# PROC-002 - Dysfonctionnement d'une imprimante

## Catégorie

Matériel et périphériques

## Symptômes

- Impression impossible.
- Imprimante hors ligne.
- Documents bloqués dans la file d'impression.
- Qualité d'impression dégradée.

## Procédure

1. Vérifier que l'imprimante est allumée.
2. Vérifier la connexion réseau ou USB.
3. Contrôler les messages affichés sur l'imprimante.
4. Vérifier la file d'impression.
5. Vérifier que la bonne imprimante est sélectionnée.
6. Relancer l'impression d'un document de test non sensible.

## Sécurité

Ne pas imprimer de données de patients pour effectuer un test.

## Escalade

Transmettre au support matériel si le problème persiste.
